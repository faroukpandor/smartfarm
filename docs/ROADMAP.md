# SmartFarm Roadmap

## Phase 0 — Foundation
- [x] Product boundary defined
- [x] Offline-first architecture defined
- [x] Core data model defined
- [ ] Vite/React application shell
- [ ] IndexedDB/Dexie repository layer
- [ ] Zod domain schemas
- [ ] Basic PWA manifest/service worker

## Phase 1 — Operational MVP
- Farm setup
- Fields and crop cycles
- Livestock
- Inventory
- Tasks
- Expenses and sales
- Dashboard
- JSON/CSV export

## Phase 2 — Climate-smart operations
- Weather observations
- Water-use tracking
- Irrigation scheduling
- Soil/field observations
- Enterprise gross margins
- Production-risk flags with transparent rules

## Phase 3 — AgriSage360 integration
- Advisory request/response contracts
- Field-service workflows
- Farmer/agent profiles
- Research and evidence links
- Optional AI-assisted summaries with provenance

## Phase 4 — Ecosystem
- Optional sync
- Cooperative/group views
- Market intelligence
- Sensor/IoT adapters
- Benchmarking with privacy controls

## Critical gate
Do not add AI, sensors or complex integrations until the basic farm records are reliable, exportable and usable offline.
