# UI Direction — Visual Thinking × Visual Storytelling

This repository adopts the Farouk Collective portfolio UI standard: web applications should be inspired by the *underlying interaction principles* associated with Napkin AI and Gamma AI, while remaining visually and commercially distinct.

## Experience model
**Goal → Source/Idea → Structure → Evidence → Visualise → Decide → Act → Share**

## Required characteristics
- clear purpose and one primary action;
- calm editorial composition, strong typography and generous whitespace;
- progressive disclosure rather than dashboard clutter;
- meaningful cards and visual blocks;
- diagrams, flows, timelines, maps or comparisons where they improve comprehension;
- visible source/evidence/status where relevant;
- narrative screen titles that explain the user's outcome;
- useful output/share/export modes;
- responsive, accessible and mobile-first behaviour;
- lightweight, portable and maintainable implementation.

## Shared conceptual primitives
**Workspace/Canvas · StoryCard · VisualNode · EvidenceChip · SourceBadge · WorkflowStep · InsightPanel · DecisionCard · OutputMode · Dossier/Presentation Renderer**

These are patterns, not mandatory component names.

## Domain identity
The common interaction grammar must not make applications look identical. The domain supplies the visual language and terminology.

## Non-copying boundary
Do not copy Napkin AI or Gamma AI screens, branding, proprietary assets, code or distinctive trade dress. Reinterpret visual-thinking and visual-storytelling principles through the Farouk Collective design system.

## Engineering rule
Do not migrate frameworks merely for aesthetics. Prefer the repository's existing architecture, semantic HTML, lightweight visual primitives, accessibility, PWA/offline-first behaviour where appropriate, and portable/free infrastructure.

## Release gate
UI work is complete only when the journey is understandable, visualisation adds meaning, evidence is distinguishable from inference, outputs are useful, accessibility/responsiveness are sound, and the product retains its own identity.
