# Farouk Collective UI Direction — Visual Thinking × Visual Storytelling

This product follows the portfolio-wide Farouk Collective interface direction.

## Inspiration
Draw from the interaction principles associated with Napkin AI and Gamma AI: visual reasoning, structured visual artefacts, narrative composition, progressive disclosure, and polished outputs. Do **not** copy proprietary screens, branding, assets, code, or distinctive trade dress.

## Core journey
**Goal → Source/Idea → Structure → Evidence → Visualise → Decide → Act → Share**

## UI requirements
- Make purpose and the current task immediately clear.
- Give important views one clear primary action.
- Prefer calm editorial layouts, strong typography, whitespace, and meaningful content blocks over dashboard clutter.
- Use diagrams, flows, timelines, maps, matrices, cards, or other visual structures when they improve understanding.
- Distinguish source, evidence, generated content, inference, assumptions, status, and uncertainty.
- Use progressive disclosure for complex workflows.
- Make useful outputs reusable/shareable where appropriate.
- Responsive, accessible, performant, portable, and offline-first where appropriate.
- Avoid decorative AI noise, fabricated evidence, fake metrics, and unsupported authority claims.

## Shared patterns
Where useful, converge on lightweight equivalents of: Workspace/Canvas, StoryCard, VisualNode, EvidenceChip, SourceBadge, WorkflowStep, InsightPanel, DecisionCard, OutputMode, and Dossier/Presentation Renderer.

## Engineering rule
**Inspect first. Preserve what works. Improve incrementally.** Do not introduce framework migrations or heavy dependencies merely for visual consistency. Preserve this product's architecture and brand identity.

## Release gate
The journey must be understandable; visualisation must add meaning; provenance/evidence must remain clear; outputs must be useful; and mobile/accessibility/performance must be acceptable.

**Collective principle:** add as much value to as many lives as possible, with fairness, transparency, evidence, and ownership/provenance clarity.
